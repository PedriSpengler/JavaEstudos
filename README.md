# ☕ Trilha de Estudos em Java

Este repositório é dedicado ao meu aprendizado e prática contínua da linguagem Java. O objetivo principal é documentar minha evolução técnica, consolidar conceitos e manter um portfólio de estudos bem organizado.

## 🎯 Metodologia de Estudo

Este projeto é guiado por duas referências principais:

*   **[Roadmap.sh (Java)](https://roadmap.sh/java):** Utilizado como mapa principal para ditar a ordem dos conteúdos e garantir que o aprendizado siga uma trilha lógica, do básico ao avançado, cobrindo as tecnologias exigidas pelo mercado.
*   **[W3Schools (Java Tutorial)](https://www.w3schools.com/java/):** Utilizado como material de apoio teórico, consulta rápida de sintaxe e resolução de exercícios de fixação de conceitos.

## 🛠️ Tecnologias e Ferramentas

*   **Linguagem:** Java
*   **Ambiente de Desenvolvimento (IDE):** IntelliJ IDEA *(sugestão)*
*   **Controle de Versão:** Git e GitHub

## 📁 Estrutura do Repositório

O repositório está dividido por tópicos para facilitar a navegação pelos conceitos estudados:

- `01-basico/`: Sintaxe, Variáveis, Tipos de Dados e Operadores.
- `02-estruturas-de-controle/`: Condicionais (If/Else, Switch) e Loops (For, While).
- `03-metodos/`: Declaração de métodos, parâmetros, retorno e sobrecarga.
- `04-poo/`: Programação Orientada a Objetos (Classes, Herança, Polimorfismo, Abstração).
- `05-estruturas-de-dados/`: Arrays, ArrayList, LinkedList, HashMap.
- `06-tratamento-de-erros/`: Try/Catch e Exceptions.
- `07-avancado/`: Threads, Lambda, Streams API e manipulação de arquivos (I/O).

## 🚀 Como Executar

1.  Clone este repositório para a sua máquina local:
    ```bash
    git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)
    ```
2.  Abra o projeto na sua IDE de preferência.
3.  Navegue até a pasta do conceito que deseja testar.
4.  Compile e execute o arquivo `.java` que contém o método `public static void main(String[] args)`.
